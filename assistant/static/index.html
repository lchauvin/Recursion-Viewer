    Cle d'API Ollama

    —

    Inutile pour un Ollama local ; requise pour Ollama Cloud (les modeles en :cloud) ou une instance protegee. Elle se lit dans OLLAMA_API_KEY, depuis vos variables d'environnement ou le fichier .env a la racine du projet — jamais saisie ni enregistree ici. Relancez le serveur apres l'avoir changee.
